# 留守番電話 (Rusuden)

Android スマホをキャリア契約なしで留守番電話にするアプリです。

着信があると、設定した秒数の呼び出しのあとに自動で応答し、応答メッセージ(合成音声)を再生してから「ピー」という発信音のあとに相手の伝言を録音します。録音した伝言はアプリ内の一覧から再生・削除できます。

## 主な機能

- **自動応答** — 設定した秒数(初期値: 15秒)呼び出しが続くと自動で電話に出ます
- **応答メッセージ** — 設定画面で文章を変えられます(日本語の合成音声で読み上げ)
- **伝言の録音** — 最大録音時間(初期値: 60秒)まで録音し、終わると自動で切断
- **伝言一覧** — 電話番号・日時・長さを表示。タップで再生、ゴミ箱ボタンで削除
- **新しい伝言の通知**
- **手動応答もOK** — 着信画面の「応答」を押せば普通に通話できます

## APK のダウンロード

GitHub Actions がプッシュのたびに APK を自動ビルドします。

1. このリポジトリの **Releases** ページを開く
2. 最新リリースの `rusuden.apk` をスマホでダウンロード
3. ダウンロードしたファイルを開いてインストール
   (「提供元不明のアプリのインストール」を許可する必要があります)

## 初期設定(重要)

1. アプリを開き「**デフォルトの電話アプリに設定**」ボタンを押して許可する
   (Android の仕様上、通話に自動応答するにはアプリが「電話アプリ」である必要があります)
2. **マイクの許可**(と通知の許可)を与える
3. 「自動応答」スイッチがオンになっていることを確認

## 設定項目

| 項目 | 初期値 | 説明 |
|---|---|---|
| 応答までの秒数 | 15秒 | この秒数呼び出しが続くと自動応答します |
| 最大録音時間 | 60秒 | これを超えると自動で通話を切ります |
| 応答メッセージ | ただいま電話に出ることが… | 合成音声で相手に読み上げる文章 |

## 仕組みと制限事項(必ずお読みください)

- Android はセキュリティ上、アプリが通話音声を直接録音することを制限しています。そのためこのアプリは自動応答時に**スピーカーフォンをオンにして、マイク経由で相手の声を録音**します。
  - 応答メッセージの聞こえ方や録音の音質は**機種によって差があります**。お使いの機種でうまく動くか、まず自分の別の電話からかけてテストしてください。
  - 録音中はスピーカーから相手の声が流れます。周囲に人がいる場所ではご注意ください。
- 応答メッセージの読み上げには端末のテキスト読み上げエンジン(Google TTS など)を使います。日本語音声データがインストールされている必要があります(ほとんどの端末で標準搭載)。
- 通話の録音に関する法律・マナーは地域や状況によって異なります。利用は自己責任でお願いします。
- 対応 OS: Android 8.0 (API 26) 以上

## 開発者向け

```bash
# デバッグビルド
./gradlew assembleDebug
# 出力: app/build/outputs/apk/debug/app-debug.apk
```

主要なソース:

- `app/src/main/java/com/rusuden/app/AnsweringInCallService.kt` — 自動応答・録音の中核 (InCallService)
- `app/src/main/java/com/rusuden/app/InCallActivity.kt` — 着信・通話画面
- `app/src/main/java/com/rusuden/app/MainActivity.kt` — 伝言一覧・セットアップ
- `app/src/main/java/com/rusuden/app/SettingsActivity.kt` — 設定画面
